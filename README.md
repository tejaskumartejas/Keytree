# Sachren Hospital website recreation

A responsive, static website recreation based on publicly accessible information from [sachrenhospital.in](https://sachrenhospital.in/).

## Files
- `index.html` — page structure and public-facing content
- `styles.css` — responsive layout and styling
- `script.js` — mobile navigation

## Preview locally
Open `index.html` in a browser. No build tools or paid services are required.

## Important
This is an independent recreation for review, not the official hospital website. It does not submit appointment requests or store patient information. Verify all medical service details, phone numbers, and facility information with the hospital before publishing. The current design uses CSS illustrations rather than copying the source site's photos or logo.
